# M6.8 工具栏本机时间验收清单

## 前置条件

- 已启用 Fishbone Planner 插件。
- 鱼骨画布视图可见。

## 验收步骤

1. 打开鱼骨画布视图，确认右侧工作台中不再出现“时间 / 天气”模块。
2. 打开“模块管理”，确认模块列表里不再出现“时间 / 天气”。
3. 查看顶部工具栏，确认标题、视图控制和右侧按钮组恢复为原本的横向格局，没有因为时间信息被挤到多行或居中。
4. 查看右上角操作区，确认本机时间与日期位于按钮组边框外，并横向对齐在“新建任务”按钮下方。
5. 等待到下一分钟，确认右上角时间自动刷新，鱼骨画布不整体重绘或闪烁。
6. 点击“新建任务”，确认按钮仍能正常打开新建任务弹窗。
7. 检查设置页，确认不再显示天气地区、经纬度、联网天气源等天气配置项。

## 通过标准

- 当前 UI 不再提供任何天气联网同步入口。
- 本机时间始终显示在右上角按钮组外侧，作为对齐“新建任务”按钮下方的独立信息块。
- `npm run build` 和 `node scripts/validate-m6-8-time-weather.js` 通过。
