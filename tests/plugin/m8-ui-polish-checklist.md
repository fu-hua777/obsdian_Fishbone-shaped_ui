# M8 UI 精修验收清单

## 前置条件

- Fishbone Planner 插件已启用。
- 打开鱼骨画布视图。
- Vault 中至少存在 3 条主线、多个任务、至少一条 relation 和一个短期分支主线。

## 验收步骤

1. 查看顶部工具栏，确认标题、视图模式、操作按钮和本机时间保持原布局，但整体更紧凑统一。
2. 查看顶部按钮，确认“今天、跳转、适应窗口、显示/隐藏关系、模块管理、新建任务、新建主线、刷新”等按钮都有图标和短文字。
3. 查看统计行，确认任务、主线、泳道、关系、聚合、范围、画布、时间都以轻量 chip 展示。
4. 查看画布背景，确认深色层次、网格和边框不压过任务内容。
5. 查看顶部日期轴，确认今天/中心日期高亮清晰，普通日期不会在缩放后大量重叠。
6. 查看左侧主线标签，确认主线名称、图标/颜色、子信息足够醒目，能直观看出每条主线含义。
7. 新建或编辑一条主线，填写图标名，例如 `heart` 或 `book-open`，确认保存后左侧主线标签显示对应图标。
8. 查看任务节点，确认节点为紧凑一行，优先级标签、checkbox、标题不互相挤压。
9. 悬停任务节点，确认 tooltip 可读，不遮挡当前任务标题。
10. 查看 relation 虚线，确认线条、箭头和中文标签不喧宾夺主，hover 后可识别。
11. 查看短期分支主线，确认分支标签为透明标注，不遮挡分支任务。
12. 查看右侧模块，确认每个模块标题左侧都有与模块功能匹配的图标。
13. 查看右侧任务行，确认有主线颜色点或左侧色条，能快速识别任务所属主线。
14. 查看右侧模块，确认模块像独立小面板，内部列表可滚动，模块排序/高度调整入口仍可用。
15. 拖动右侧模块和下方工作台列标题，确认插入线和拖拽中状态清晰。
16. 查看下方工作台，确认三列标题有状态图标，任务行更紧凑，左侧图标与右侧主线标签颜色对应。
17. 查看快速笔记输入框，确认悬浮在画布底部中间，提示格式清楚，聚焦态明显，仍可预览和写入任务。

## 通过标准

- UI 精修不破坏 M5-M7 的核心交互。
- 画布、右侧模块和下方工作台视觉上属于同一套界面。
- 紧凑化后文本不出现明显溢出、重叠或不可读。
