# M8 UI 精修验收清单

## 前置条件

- Fishbone Planner 插件已启用。
- 打开鱼骨画布视图。
- Vault 中至少存在 3 条主线、多个任务、至少一条 relation 和一个短期分支主线。

## 验收步骤

1. 查看顶部工具栏，确认标题、视图模式、操作按钮和本机时间保持原布局，但整体更紧凑统一。
2. 查看顶部按钮，确认“今天、跳转、适应窗口、显示/隐藏关系、模块管理、新建任务、新建主线、刷新”等按钮都有图标和短文字。
3. 查看顶部缩放区域，确认有缩小按钮、百分比读数、放大按钮和时间密度读数。
4. 点击缩小/放大按钮，确认画布以当前可视区域中心缩放，日期轴和主线标签同步更新。
5. 查看本机时间，确认它位于顶部按钮下方但不压住“任务/主线/泳道/关系”等统计 chip。
6. 查看标题区、视图控制区和右侧操作区，确认这些顶层模块没有大块边框背景互相覆盖。
7. 查看统计行，确认任务、主线、泳道、关系、聚合、范围、画布、时间都以轻量 chip 展示。
8. 查看画布背景，确认深色层次、网格和边框不压过任务内容。
9. 查看顶部日期轴，确认今天/中心日期高亮清晰，普通日期不会在缩放后大量重叠。
10. 查看左侧主线标签，确认主线名称、图标/颜色、子信息足够醒目，能直观看出每条主线含义。
11. 新建或编辑一条主线，填写图标名，例如 `heart` 或 `book-open`，确认保存后左侧主线标签显示对应图标。
12. 查看任务节点，确认节点为紧凑一行，优先级标签、checkbox、标题不互相挤压。
13. 查看不同状态的任务节点，确认完成、进行中、阻塞、收件箱任务有可识别但不过重的视觉差异。
14. 悬停任务节点，确认 tooltip 可读，不遮挡当前任务标题。
15. 查看 relation 虚线，确认线条、箭头和中文标签不喧宾夺主，hover 后可识别。
16. 查看短期分支主线，确认分支标签为透明标注，不遮挡分支任务。
17. 查看右侧模块，确认每个模块标题左侧都有与模块功能匹配的图标。
18. 查看右侧模块标题栏，确认数量/状态是小胶囊，收起/展开和隐藏是图标按钮，不再占用“折叠/隐藏”文字按钮宽度。
19. 查看右侧任务行，确认有主线颜色点或左侧色条，能快速识别任务所属主线。
20. 查看右侧模块，确认模块像独立小面板，内部列表可滚动，模块排序/高度调整入口仍可用。
21. 拖动右侧模块和下方工作台列标题，确认插入线和拖拽中状态清晰。
22. 查看下方工作台，确认不再显示“状态工作台”和说明性副标题，面板直接进入待办、进行中、已完成三列。
23. 查看下方工作台，确认三列标题有状态图标，任务行更紧凑，左侧图标与右侧主线标签颜色对应。
24. 查看快速笔记输入框，确认悬浮在画布底部中间，提示格式清楚，右侧是发送图标按钮而不是普通文字按钮。
25. 在快速笔记输入框输入一条任务并点击发送图标，确认仍先生成候选预览，之后可确认写入或编辑后创建。

26. 查看顶部区域，确认本机时间是独立无边框信息展示，位于按钮模块外侧，不与下方统计 chip 重合。
27. 查看右侧任务状态下拉、任务右键菜单、新建/编辑任务弹窗、快速输入候选和任务 hover tooltip，确认可见状态显示为中文短标签，而不是 raw `todo/doing/inbox`。
28. 查看右侧“今日聚焦 / 本周重点”任务行，确认优先级在标题行右侧、状态为短胶囊，下方 meta 只保留主线和日期，不会撑高任务行。
29. 查看下方待办、进行中、已完成任务行，确认行高更紧凑，左侧主线图标和右侧主线标签仍可识别，拖拽换状态与勾选完成仍可用。

## 通过标准

- UI 精修不破坏 M5-M7 的核心交互。
- 画布、右侧模块和下方工作台视觉上属于同一套界面。
- 紧凑化后文本不出现明显溢出、重叠或不可读。
- 顶部本机时间不再与统计 chip 重叠，顶部大模块边框不会压住标题区。
- 快速笔记视觉上是独立输入胶囊，但交互仍是预览候选后再写入。
- 右侧模块标题栏保留操作能力，但不再被文字操作按钮撑宽或喧宾夺主。
- 下方工作台不再用说明性标题占高度，三列状态模块成为第一视觉层。
- 可见状态文本已本地化，但任务文件中的 `status` 值仍保持 schema 原值。
- 右侧与下方模块任务行保持单行可扫读，不因状态、优先级或主线标签导致明显换行和高度跳动。
