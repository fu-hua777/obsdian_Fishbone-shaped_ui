# M8 UI 精修与观感优化

## 目标

在不改变 M5-M7 数据读写和交互闭环的前提下，把鱼骨画布视图向概念图中的统一规划工作台推进：界面更紧凑、层级更清楚、画布更像工作区域，右侧和下方模块减少臃肿感。

## M8.1：视觉收口

- 统一顶部工具栏的玻璃感容器、按钮密度、标题输入框和本机时间展示。
- 优化统计 chip，使信息更接近概念图顶部的轻量状态栏。
- 优化画布背景、边框、网格、顶部日期轴和主线脊骨，让画布有明确的深色层次和聚焦感。
- 优化主线标签，强化左侧图标/颜色识别，减少大卡片感。
- 优化任务节点为更轻量的一行胶囊，减少遮挡，同时保留优先级、完成状态和 hover 信息。
- 优化关系线、分支主线标签和短期主线视觉，使其更像画布标注而非实体卡片。
- 优化右侧模块和下方工作台，降低边框厚重感、压缩间距、强化彩色标签和内部滚动。
- 保留快速笔记输入框，提示输入格式，不接入外部 AI。

## M8.2：交互细节

- 针对 hover、拖拽、调整高度、排序插入线等状态做统一高亮。
- 将顶部操作按钮改为图标加短文字，提升工具栏识别速度。
- 顶部缩放读数升级为 `缩小 / 百分比 / 放大` 控件，并保留时间密度读数，贴近概念图中的缩放控制。
- 快速笔记输入框增加聚焦态和格式提示可读性，继续保持不接入外部 AI。
- 检查低缩放比例下日期轴、任务节点和关系标签是否重叠。
- 检查下方工作台高度较小时的滚动、标题和任务行是否可读。

## M8.3：真实界面验收

- 为右侧模块标题补充稳定图标，使今日聚焦、本周重点、进度概览、主线进度和每日总结在视觉上可快速区分。
- 为下方待办、进行中、已完成三列补充状态图标，减少单纯文字标题的弱识别问题。
- 为右侧任务行补充主线颜色点和左侧色条，使任务所属主线在小模块里也可扫描。
- 主画布左侧主线标签使用主线 `icon` 字段渲染 Obsidian/Lucide 图标，并在新建/编辑主线弹窗中提供图标输入。
- 在真实 Obsidian 中刷新插件产物。
- 对比概念图检查：顶部、画布、主线、任务节点、右侧模块、下方工作台和快速笔记。
- 记录仍不符合预期的细节，进入下一轮局部精修。

## M8.6：顶部避让与任务状态语义

- 顶部本机时间保留在新建任务按钮下方，但 toolbar 需要给它预留垂直空间，避免覆盖统计 chip。
- 顶部标题区、视图控制区和右侧操作区改为轻量无边框容器，避免大块边框背景与标题视觉重叠。
- 任务节点增加状态语义：完成任务更接近概念图的绿色完成状态，进行中有轻微高亮，阻塞任务有红色提示，收件箱任务保留弱化的待整理状态。
- 这些改动只影响 UI，不改变任务 schema、任务写入或状态切换逻辑。

## M8.7：快速笔记输入胶囊

- 快速笔记继续作为画布底部独立输入框，不回到右侧或下方模块容器。
- 输入动作从文字按钮改为发送图标按钮，贴近概念图中的快速输入样式，同时保留“先预览候选，再确认写入”的闭环。
- 输入框保持格式提示和 hover/focus 可读性，按钮保持固定尺寸，避免改变输入框高度或挤压提示文本。

## M8.8：右侧模块标题栏减噪

- 右侧模块的“收起/展开”和“隐藏”操作保留，但从文字按钮改为图标按钮。
- 模块数量/状态读数保持为小胶囊，减少标题栏文字拥挤。
- 标题栏继续支持拖动排序和高度调整，不改变模块管理、折叠、隐藏的持久化逻辑。

## M8.9：下方工作台紧凑化

- 下方工作台去掉“状态工作台”和说明性副标题，直接展示待办、进行中、已完成三列。
- 面板仍保留 `aria-label` 语义、上下高度调节、列排序和任务拖拽换状态能力。
- 三列获得更多垂直空间，整体更接近概念图底部状态模块。

## M8.10：状态文本本地化
- 所有可见任务状态使用中文短标签：待办、进行、完成、阻塞、取消、收件。
- 下拉框、右键菜单和快速状态切换保留原始 `TaskStatus` value，不改变任务 schema 或写回逻辑。
- 快速输入候选、任务 tooltip、任务节点和状态更新通知也使用中文状态文本，减少英文状态噪声。

## M8.11：顶部信息区避让
- 本机时间不再依赖 toolbar 内的绝对定位，改为视图容器中的独立静态信息行，避免与统计 chip 重合。
- 顶部标题、视图控制区和右侧操作区使用稳定三列布局，标题输入与控制模块保持透明无边框，避免大块边框背景互相覆盖。
- 窄窗口下顶部区域自动改为单列换行，优先保证标题、按钮、时间和统计 chip 不重叠。

## M8.12：模块任务行可扫读优化
- 右侧“今日聚焦 / 本周重点”任务行减少表单感：优先级提升到标题行右侧，状态下拉压缩为短胶囊，主线和日期保留为轻量 meta。
- 下方待办、进行中、已完成任务行继续降低高度和间距，保留左侧主线图标、右侧主线彩色标签和拖拽换状态能力。
- 任务行文本一律单行截断，优先避免模块内部文字换行导致高度跳动或遮挡。

## M8.13：画布主线标签与日期轴精修
- 主线标签把任务数从副标题中提到标题行右侧的独立徽标，副标题只保留“用户主线 / 临时泳道”等类型说明。
- 主线标签增加左侧细色条和更稳定的文本布局，减少大卡片感，同时保留图标、状态 chip、点击编辑、右键菜单和长按排序。
- 日期轴的中心日期 / 今天增加小锚点，与下方垂直参考线形成更明确的当前日期定位。

## M8.14：画布任务节点焦点状态精修
- 任务节点按显示日期增加今天、中心日期、过期三个只读视觉 class，不改变任务 schema 或状态写回。
- 今天 / 中心日期任务增加轻量聚焦光效，帮助用户在时间轴中快速定位当前关注任务。
- 未完成且已过期任务使用轻量红色提示；完成和取消任务不标记为过期。
- 高 / 中 / 低优先级胶囊按严重程度显色，提升鱼骨主画布任务节点扫读效率。

## 非目标

- 本阶段不改变任务 schema。
- 本阶段不改变 relation、主线、任务写回逻辑。
- 本阶段不重新引入天气模块或外部 AI 输入。
